# requirements-server.txt

# Minimal dependency set for RUNNING the FastAPI service (main.py) — this is
# what you point Render's build at. Deliberately excludes ingestion-only
# packages (pypdf, pdf2image, pytesseract, beautifulsoup4, lxml) and the
# unused local-embedding ML stack (torch, transformers, sentence-transformers,
# scikit-learn, scipy) that were never removed from requirements.txt after
# embeddings moved to the Gemini API — those alone are 1-2GB+ and would
# blow Render's free-tier build/RAM limits for no benefit, since nothing in
# main.py's import chain needs them.
#
# Run `scripts/ingest.py` locally (or anywhere with more RAM/disk) using the
# full requirements.txt instead — its only output that the server needs is
# data/processed/chunks.jsonl (committed to git) + the Qdrant Cloud
# collection it upserts into.
